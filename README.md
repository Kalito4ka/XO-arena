# XO-arena

Курсовой проект: серверная часть веб-приложения «Крестики-нолики».

Планируются три режима: классический, ультимативный и пожирающий, а также игра по приглашению, онлайн-подбор и таблицы лидеров.

## Текущее состояние

Настроены Docker Compose, Nginx, Apache с PHP и PostgreSQL. Работают стартовая страница, проверка подключения к БД и API списка режимов. Игровая логика пока не реализована.

## Запуск

Требуется запущенный Docker Desktop.

1. Откройте терминал в папке проекта.
2. Скопируйте настройки, если `.env` ещё не создан:

   ```powershell
   Copy-Item .env.example .env
   ```

3. Задайте пароль БД в `.env`.
4. Запустите приложение:

   ```powershell
   docker compose up --build -d
   ```

5. Откройте [http://localhost:8080](http://localhost:8080).

Для остановки с сохранением данных БД:

```powershell
docker compose down
```
